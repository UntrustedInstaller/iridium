*Osmium's periodic neighbor.*  
A work in progress C implementation of OsmiumOS

## IMPORTANT!
*We are nearing the end of Iridium's initial purpose. Milestone 6 is the planned final release of the 16-bit Osmium sibling OS.*  
*Once this code returns to Osmium, Iridium will be a vastly more complex operating system.*

##  Why?
* I absolutely SUCK at assembly, and migrating Osmium (or most of it) to C allows me to increase the scope of the OS.  
* Making a seperate repo for the C migration allows me to experiment and guinea-pig things here without affecting Osmium's codebase.

## What to expect?
* Once Iridium reaches M5, the code will be migrated back into Osmium. Iridium's builds now brand as OsmiumOS in preparation.
* The Iridium project will live on after migration as a separate thing (possibly a 32-bit implementation).
