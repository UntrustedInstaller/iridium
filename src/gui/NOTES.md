# GUI

GUI toolkit, compositor, window manager, widgets.

## Planned

- Immediate-mode GUI core
- Widgets: button, label, textbox, slider, checkbox, listbox, window frame
- Motif 3D bevel rendering (highlight/face/shadow/dark-shadow)
- Purple accent color scheme
- Window manager: dragging (dithered outline), resize, minimize (genie effect), close
- Taskbar with start menu ("shelf")
- Font renderer for 8×16 bitmap glyphs
- Mouse cursor rendering

## Design references

- Dear ImGUI (API design — immediate mode)
- SerenityOS (button proportions, pixel-perfect feel)
- Windows 9X / Motif (3D bevel system, grey palette)
- Mac OS 8/9 (title bar notches, platinum aesthetics)
